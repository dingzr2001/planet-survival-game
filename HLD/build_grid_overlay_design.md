# 建造栅格显示设计

## 目标与交互

- 地表场景中按 `G` 打开或关闭建造栅格，默认关闭。
- 栅格必须与实际建造吸附完全重合，帮助验证占地、负坐标和连续放置。
- 显示仅是辅助表现，不改变建造规则、占用状态或玩家控制。

## 设计

`BuildGridOverlay` 直接绑定当前 `GameSessionState.Buildings.Grid`，以该对象的 `Origin` 和
`CellSize` 生成 XZ 平面线框，因此显示与 `BuildingPlacementController` 使用同一数据源，不复制
栅格参数。`GameBootstrap` 在创建建造系统时注入栅格和主相机。

组件把相机视口四角投影到建造平面，只生成覆盖当前可见区域并额外向外扩一格的线段。网格仅在
相机跨过单元格边界或视野范围改变时重建；关闭时禁用渲染但仍监听快捷键。线条使用半透明材质，
略高于地面，建造占地预览仍以更高的排序层显示。

## 职责边界

| 类型 | 职责 |
| --- | --- |
| `BuildGrid` | 世界坐标换算、吸附与占用，是栅格规则的唯一来源 |
| `BuildGridOverlay` | 快捷键、可见范围计算与线框 Mesh 生命周期 |
| `GameBootstrap` | 创建组件并注入当前会话栅格和相机 |

## 验收与限制

- 按 `G` 后栅格立即出现，再按一次消失；暂停时也可切换。
- 线条应穿过整数建造单元边界，建筑预览的边缘应与线条重合。
- 玩家移动时栅格持续覆盖屏幕，不出现固定世界边界。
- Edit Mode 测试验证默认隐藏、切换状态、线拓扑和网格对齐。
- 当前快捷键使用项目已有的旧版 Input API；若项目迁移到 Input System，应把按键读取替换为输入动作，显示与网格生成逻辑无需变化。
