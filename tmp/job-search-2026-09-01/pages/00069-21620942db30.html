Description

Information Systems Solutions (ISS) is seeking a Software Engineer Ito support the NIWC PAC Information Technology Management Support Services contract. Software Engineers research, design, and develop computer and network software or specialized utility programs.


This position is 100% onsite.


Specific duties include, but are not limited to the following:

· Develop and maintain secure software applications using Python, JavaScript, and other languages across unclassified and classified environments.

· Implement secure coding practices and embedded security throughout the development lifecycle in alignment with DoD directives and DISA STIGs.

· Build and optimize intuitive web-based interfaces and Web Service APIs (REST, SOAP, GraphQL) to aggregate multi-source data.

· Utilize Agile/Scrum methodologies, Test-Driven Development (TDD), and modular object-oriented design within a CI/CD DevSecOps pipeline.

· Design, publish, and maintain database schemas, dictionaries, and system architectures while proactively resolving technical debt.

· Collaborate with stakeholders to translate user requirements into technical specifications, provide system integration support, and author technical documentation.
