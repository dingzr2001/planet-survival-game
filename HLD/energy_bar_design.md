# 能量棒简要设计文档

## 1. 目标与定位

能量棒是登陆任务携带的高密度应急食品，用于在探索过程中快速恢复饱食度，并小幅改善玩家精神状态。

当前版本要求：

- 能量棒不可制作，也不从野外资源点产出。
- 每次开始新游戏或重新开始时，在登陆舱物资仓中存放固定数量。
- 玩家必须先将其从物资仓转移到背包，之后才能食用。
- 食用后消耗一根，并立即恢复饱食度和精神值。

## 2. 核心数值

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 单根热量 | `500 kcal` | 高密度应急食品 |
| 热量换算 | `25 kcal = 1 点饱食度` | 满饱食度对应约 `2500 kcal` |
| 饱食度恢复 | `20` | 由热量统一换算，不在物品上重复配置 |
| 精神值恢复 | `6` | 提供小幅士气收益，不替代主要精神恢复手段 |
| 开局数量 | `12` | 全部存放于物资仓 |
| 单个容量占用 | `1` | 便于携带，但仍占用背包容量 |
| 最大堆叠 | `12` | 开局物资可以放在一个物品槽中 |

现有饱食度每游戏小时降低 `2` 点，因此一根能量棒约能抵消 `10` 个游戏小时的基础饥饿消耗。12 根合计提供约 `5` 个游戏日的应急食物缓冲。

## 3. 开局存放位置

能量棒存放在登陆舱一层（Deck 1）的 `Cargo Storage Racks` 中，对应运行时的 `GameSessionState.CargoStorage`。

它不会出现在：

- 玩家初始背包；
- 生活舱冰箱；
- 野外采集节点；
- 制作配方或制作产物。

开始新游戏和重新开始时，旧会话库存会先被清空，再向物资仓加入 12 根能量棒。普通场景切换不会刷新数量，避免玩家反复进出场景复制物资。

## 4. 使用流程

1. 玩家进入登陆舱一层物资区。
2. 与 `Cargo Storage Racks` 交互并打开仓储界面。
3. 将能量棒从物资仓转移到玩家背包。
4. 在背包中点击 `Use`，或将其放入快捷栏后使用。
5. 系统将 `500 kcal` 换算为 `20` 点饱食度，并额外恢复 `6` 点精神值。
6. 属性恢复值受各自最大值限制，成功使用后物品数量减少一根。

玩家死亡或无法接收物品效果时不能使用，物品也不会被消耗。

## 5. 职责划分

| 类型或资源 | 职责 |
| --- | --- |
| `EnergyBar.asset` | 保存物品名称、图标、热量、堆叠和精神恢复配置 |
| `NutritionBalance` | 将 kcal 统一换算为饱食度 |
| `PlayerInventory` | 校验并消费物品，触发营养和附加效果 |
| `PlayerSurvival` | 将热量恢复应用到玩家饱食度 |
| `GameSessionState` | 保存跨场景库存，并重置开局物资 |
| `GameFlowController` | 在新游戏和重新开始时注入初始能量棒 |

热量换算与具体物品分离，后续增加其他食物时只需配置 kcal；所有食物共享同一换算规则，避免每种食物分别维护容易失配的饱食度数值。

## 6. 不可制作规则

当前项目没有制作系统，能量棒只通过开局物资注入，因此现阶段无法制作。未来加入制作系统时，能量棒不得注册到配方、蓝图或制作产物列表；若需要新的可制作食品，应创建独立物品定义。

## 7. 验收标准

- 新游戏进入登陆舱物资层后，物资仓中存在 12 根能量棒。
- 生活舱冰箱和玩家初始背包中没有能量棒。
- 能量棒可以从物资仓转移到背包并正常堆叠。
- 饱食度为 `30`、精神值为 `40` 时食用一根，结果分别为 `50` 和 `46`。
- 属性接近上限时恢复结果不会超过最大值。
- 食用成功后数量减少一根；使用失败时不消耗。
- 场景切换不会补充能量棒，新游戏或重新开始会恢复为 12 根。
- 能量棒不存在采集来源和制作配方。

## 8. 后续调整点

- 根据实际游玩节奏调整单根热量、精神恢复量或开局数量。
- 增加饱食度已满时的使用提示，避免浪费食物。
- 制作系统上线后，为不可制作物品增加明确的数据标记和自动化校验。
- 如增加食品保质期，可为能量棒设置较长保质期，突出应急储备定位。
