# 电力桩设计

## 目标

电力桩是有方向的能源路由建筑。玩家为其配置多个输入和有序输出；输出列表本身就是供电优先级，而非自动平摊的电网。

电力桩占用一个 half-cell，边长为普通建筑格的一半；放置和传送桩一样使用半格网格。

## 连线与所有权

- 输入端可选择已完成的太阳能板或其他电力桩；输出端可选择已完成的采矿机（以及未来实现 `IPowerInput` 的电器）或其他电力桩。
- 电力桩之间可远程连接；普通发电和用电建筑只会在与当前桩相邻时出现在候选列表中。
- 一个太阳能板同一时刻只能接入一座电力桩，一个电器也只能接收一座电力桩的输出。将端点加入另一座桩时，旧归属会自动移除，避免重复计算发电或双重供电。
- 电力桩互连会自动补全另一侧的反向配置；有向环路不结算供电，避免循环制造能量。

## 每帧结算

1. 汇总所有输入发电建筑的本帧发电量，并接收上游电力桩已路由的功率。
2. 按输出列表从上到下计算每台用电建筑的额定本帧需求；采矿机当前的需求为“产出速率 × 每单位矿石耗电”。
3. 若剩余电力足以满足该需求，则一次性全额写入采矿机并继续下一项。
4. 若不足以满足下一项，则该项和后续项本帧均不供电；不会分摊或部分供电。

采矿机自身仍保留原有的小型电力缓存，因此已缓存的电能会继续被消耗；电力桩只决定新产生的太阳能如何分配。

## 视觉状态

- `PowerPoleOffline`：没有有效输入功率。
- `PowerPoleLimited`：有输入，但没有让所有已配置输出获得全额供电。
- `PowerPolePowered`：至少一个输出存在，且所有输出均获全额供电。

每座电力桩按放置顺序获得两位编号，并在世界模型上显示。右键面板保留输入－传输－输出三栏：中栏播放传输动画；端点列表及候选列表均显示建筑图标和同类建筑的两位编号，并提供上移、下移和移除按钮。
