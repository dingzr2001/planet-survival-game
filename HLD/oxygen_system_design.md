# 氧气系统简要设计文档

## 1. 目标与范围

氧气系统负责维护宇航服与着陆舱的氧气库存，按照游戏时间消耗当前供氧源，并将供氧状态同步给玩家的低氧规则。

当前版本包含：

- 宇航服氧气及随身饮用水资源。
- 着陆舱氧气及储水资源。
- 固定速率耗氧。
- 舱内、舱外供氧源自动切换。
- 低氧造成的理智和生命损失。
- 跨场景资源保持、重新开始时重置。
- 使用图标和进度条展示资源。

当前版本不包含氧气补充、制氧设备、泄漏、活动强度修正、多人耗氧以及永久存档。

## 2. 核心数值

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 宇航服氧气容量 | `600 L` | 新游戏开始时装满 |
| 着陆舱氧气容量 | `36,000 L` | 新游戏开始时装满 |
| 玩家耗氧速率 | `5 L / 游戏小时` | 暂停和死亡后不消耗 |
| 宇航服水容量 | `500 mL` | 与现有个人饮水容器共用 |
| 低氧警戒线 | `50%` | 低于该比例开始损失理智 |
| 严重低氧线 | `20%` | 低于该比例追加生命损失 |

按照默认参数，满氧宇航服可供氧 `120` 游戏小时，即约 `5` 个游戏日。数值集中在会话状态和耗氧组件中，后续可根据实际游玩节奏调整。

## 3. 状态模型

### 3.1 氧气库存

`OxygenReservoir` 是不依赖 Unity 的领域对象，维护容量、当前升数和归一化比例。它保证：

- 容量为有限正数。
- 当前氧气始终处于 `[0, Capacity]`。
- 消耗量不会超过实际库存。
- 状态实际变化后发布一次 `Changed` 事件。

宇航服资源由 `SpaceSuitResources` 聚合，其中氧气使用 `OxygenReservoir`，水使用已有的 `LiquidContainer`。

### 3.2 玩家氧气状态

`PlayerOxygen` 表示玩家当前可用氧气比例，供 HUD 和低氧规则读取。它不拥有物理库存；当前值由正在供氧的储罐归一化比例同步得到。

这种分离使库存容量可以使用真实单位，而低氧规则继续使用稳定的 `0–100` 玩家属性。

## 4. 供氧与消耗流程

供氧源按宇航服穿戴状态选择：

| 场景状态 | 宇航服状态 | 当前供氧源 |
| --- | --- | --- |
| 星球地表 | 已穿戴 | 宇航服氧气 |
| 着陆舱生活层或物资层 | 未穿戴 | 着陆舱氧气 |
| 无有效供氧源 | 任意 | 玩家氧气视为 `0` |

每次游戏时钟推进时按以下顺序结算：

1. `GameClock` 计算经过的游戏小时数。
2. `PlayerOxygenConsumption` 从当前供氧源扣除 `速率 × 时间`。
3. 将储罐剩余比例同步到 `PlayerOxygen`。
4. `PlayerHypoxia` 使用更新后的氧气比例计算理智和生命损失。

氧气消耗按游戏时间而非帧数计算，因此不同帧率和时间步拆分应得到一致结果；暂停、非正时间步和玩家死亡时不消耗。

## 5. 低氧规则

- 氧气比例不低于 `50%`：安全，不产生低氧损失。
- 氧气比例低于 `50%`：理智持续下降。
- 氧气比例低于 `20%`：在理智下降之外追加生命损失。
- 损失随氧气降低连续增大，避免跨越阈值时突然跳变。
- 氧气恢复到阈值以上后立即停止对应损失，但不返还已损失的属性。

低氧公式由纯 C# 的 `HypoxiaRule` 负责，库存和耗氧组件不得复制伤害规则。

## 6. 生命周期与 UI

`GameSessionState` 拥有宇航服资源、着陆舱氧气和着陆舱储水，因此上下甲板或进出舱不会重置库存。开始新游戏或重新开始时恢复默认值。

- 地表显示宇航服资源面板。
- 着陆舱显示独立的生命支持面板。
- 氧气和水分别使用 O₂ 与水滴贴图识别，数值与进度条显示剩余量。
- UI 只读取资源状态，不负责修改库存或执行耗氧规则。

## 7. 职责划分

| 类型 | 职责 |
| --- | --- |
| `OxygenReservoir` | 氧气库存、容量限制、消耗与变化事件 |
| `SpaceSuitResources` | 聚合宇航服氧气和饮用水 |
| `PlayerSpaceSuit` | 维护穿戴状态并发布切换事件 |
| `PlayerOxygenConsumption` | 选择供氧源并按固定速率消耗 |
| `PlayerOxygen` | 对外暴露玩家当前氧气状态 |
| `HypoxiaRule` / `PlayerHypoxia` | 计算并应用低氧影响 |
| `GameSessionState` | 管理跨场景资源生命周期 |
| `SuitResourceView` | 展示宇航服资源 |
| `LandingPodResourceView` | 展示着陆舱生命支持资源 |

## 8. 验收与扩展

验收要求：氧气不会为负或超过容量；耗氧与帧率无关；舱内外只消耗正确的供氧源；跨场景保持库存；暂停、死亡和无效时间步不消耗；资源面板显示正确图标、数值和比例。

后续增加氧气补充、泄漏或制氧机时，应直接操作已有 `OxygenReservoir`。若引入奔跑、睡眠等速率修正，应在耗氧策略层组合倍率，不修改储罐和低氧伤害规则。
