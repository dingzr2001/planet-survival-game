# 初始化游戏设计
## 游戏类型
2.5D第三人称盒游戏，类似饥荒的视角
## 游戏背景
类似火星救援的背景，主人公由于太空事故迫降某陌生行星，只能利用飞船上的物资进行生存，达到天数目标后方可获救
## 游戏实体
### 主人公（玩家）
#### 属性
1. 健康值（HP）：初始为100/100，当前健康值和健康值上限均可随特定活动增加或减少
2. 精神值：初始为100/100，当前精神值和精神值上限均可随特定活动增加或减少
3. 饱食度：初始为100/100，上限理论不可变，但是允许玩家在精神值和健康值良好的情况下略微超出上限值，也可能随者健康值降低使得饱食度无法达到上限。疾病等debuff也可能使得饱食度无法达到上限
4. 口渴值：初时为100/100，上限不可变，当前口渴值可以随进食或喝水变化

#### 动作与交互
一个主人公对象可以存在以下三种与外界环境的交互：
1. 主动操作：主人公被玩家操控，主动与另一个实体进行交互，例如吃-食物，安装-机械，驾驶-车辆，也可没有另一个实体，例如走路，跳跃
2. 被动影响：主人公被外界环境或其他实体影响，例如：被-陨石-撞击，被-闹铃-吵醒，被-太阳-晒伤等
3. 自然状态变化：随者时间流逝，饱食度与口渴值的自然衰减

### 地图
在早期版本，地图可以先做成一个平直表面而非球形，但是应该存在Z轴方向的厚度。
早期的地图可以为一个个小栅格，一个栅格为对地图操作的最小粒度。
#### 地图构成
1. 表面：主人公降落并且大部分时间位于的层面，即星球的表面，应当支持随机的地形生成，形成山丘、平原、盆地、山谷等不同地形。
2. 地下：表面以下的部分，暂时不支持主人公进入地下，但是允许主人公对地下部分进行勘测、挖掘等操作，以获取资源，安装设备或种植等
3. 大气层：地表以上的部分，成分除了氧气外，在单局内处处统一，氧气随者高度增加而慢慢减少。
4. 边界：目前先为正方形，应支持自由控制，即自定义地图大小·
