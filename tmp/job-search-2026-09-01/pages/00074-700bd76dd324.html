Web Developer I - Apps

Overview

Do you love to develop web applications that leverage the latest technology? Challenge yourself at Esri and build location-aware apps, including Field Maps and Navigator, that enable people around the globe to solve real world problems. We’re looking for smart, user-focused developers to join our agile development team and help push the boundaries of web development while putting their mark on the apps of tomorrow.

Responsibilities

  • Build and maintain scalable web applications using custom, reusable, and responsive UI components
  • Practice disciplined software engineering (such as automated testing, code reviews, and writing beautiful, pragmatic code)
  • Work closely with design teams and product owners to define, design, and implement features
  • Keep our products up to date with the latest frontend technologies

Requirements

  • 1+ years of JavaScript/TypeScript development skills, including concepts like asynchronous programming, closures, and types
  • Experience building standards compliant Web Components with tools like Stencil.js or Lit
  • Experience with HTML/CSS, including concepts like layout, specificity, cross browser compatibility, and accessibility
  • Experience working with modern Single Page Application frameworks like React, Ember or Vue
  • A sincere commitment to crafting readable and reliable code
  • Excellent problem-solving, verbal and written communication, design, development, and debugging skills
  • Bachelor's degree in computer science, engineering, mathematics, GIS, or related field

Recommended Qualifications

  • Experience working with the Ember framework
  • Familiarity with Esri’s ArcGIS platform
  • Master’s degree in computer science, engineering, mathematics, GIS, or related field
